The start is the top-left cell and the target the bottom-right cell. Loops are the share of internal walls knocked through after carving a perfect maze.

Coursework explorer (2022): 0 unfinished runs, 0 wall collisions. Map planner: 0 unfinished runs, 0 wall collisions. A* oracle: 0 unfinished runs, 0 wall collisions.
