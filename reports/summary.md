# Benchmark results

Generated by `./gradlew run --args="benchmark"`: 300 seeded mazes per configuration (seed 2022), two runs per robot on each maze. Sizes are in cells; a 15x15-cell maze is 31x31 tiles. The start is the top-left cell and the target the bottom-right cell. Loops are the share of internal walls knocked through after carving a perfect maze.

Coursework explorer (2022): 0 unfinished runs, 0 wall collisions. Map planner: 0 unfinished runs, 0 wall collisions. Route prover: 0 unfinished runs, 0 wall collisions. A* oracle: 0 unfinished runs, 0 wall collisions.
